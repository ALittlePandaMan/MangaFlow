# 字体预设

字体管理提供按需下载、名称/语言/风格搜索、语言筛选和已安装字体预览。下载后的字体进入全局字体库，可供新建文本框、默认样式和项目排版选择；不会修改现有文本框的字体。字体安装在应用数据目录，不安装到操作系统。

## 选型

| 预设 | 主要用途 | 优先语言 | 完整字体大小 |
| --- | --- | --- | --- |
| [霞鹜文楷](https://github.com/lxgw/LxgwWenKai) | 日常对白、旁白、手写 | 简体中文；也覆盖繁中、日文、英文 | 24.7 MiB |
| [霞鹜文楷 TC](https://github.com/lxgw/LxgwWenkaiTC) | 繁体字形的对白与旁白 | 繁体中文；也覆盖简中、日文、英文 | 12.5 MiB |
| [站酷快乐体](https://github.com/googlefonts/zcool-kuaile) | 轻松对白、趣味标题 | 简体中文、英文 | 1.4 MiB |
| [站酷小薇体](https://github.com/googlefonts/zcool-xiaowei) | 叙述、独白、章节标题 | 简体中文、英文 | 6.0 MiB |
| [马善政毛笔楷体](https://github.com/googlefonts/mashanzheng) | 强调、拟声词、古风标题 | 简体中文、英文 | 5.6 MiB |
| [Zen Maru Gothic](https://github.com/googlefonts/zen-marugothic) | 日文圆体对白 | 日文、英文 | 3.7 MiB |
| [Yomogi](https://github.com/satsuyako/YomogiFont) | 日文手写、便条、轻声对白 | 日文、英文 | 3.9 MiB |
| [Comic Neue](https://github.com/crozynski/comicneue) | 英文气泡对白 | 英文 | 56 KiB |
| [Bangers](https://github.com/googlefonts/bangers) | 英文大写拟声词、动作标题 | 英文 | 91 KiB |

用途为本项目的排版建议，不代表作者背书。语言标签是主要支持范围，并非完整字表保证。研究时实际检查了中、繁、日、英文样句；站酷系列、毛笔楷体和日文字体不作为完整跨语言字体推荐。渲染器遇到缺字会逐字退回内置字体，因此混排可能出现不同字形风格。

不分发微软雅黑、宋体、商业漫画字体等没有确认再分发授权的系统/商业字体。9 款预设均来自作者或 Google Fonts 仓库，逐款附有原始 OFL 1.1 全文和版权声明；这里不使用未经核实的第三方“免费字体包”。预设不修改字体二进制，也不重命名字体内部家族名。

## 下载与校验

- `backend/app/services/font_presets.py` 是唯一下载白名单。客户端只能提交预设 ID，不能提交 URL；不跟随上游重定向。
- Google Fonts 固定提交为 `45e3d5269e4a17d823f6d84470bc084dc5ae46f6`；霞鹜文楷原版固定为 `7ebd0771fda4285299670f83c398f32f32c7bef8`。每个文件保存实际下载核验的大小和 SHA-256。
- `GET /api/fonts/presets` 仅访问本地目录，不请求外网。`POST /api/fonts/presets/{id}/install` 才下载字体；同一字体不能并发下载，最多两个不同字体同时下载。
- 下载使用隐藏临时文件；校验大小、摘要及字体结构后再原子发布，不覆盖同名的非预设文件。网络中断、重定向、校验失败会删除临时文件并允许重试。
- 原始授权文本随代码保存在 `backend/app/assets/font-licenses/`，安装时复制到数据目录的 `fonts/licenses/`。重复安装有效文件不重复访问网络；删除后可再次下载。
- 安装文件名和字体资源的家族名兼容渲染器的文件名匹配。站酷小薇体的 typographic-family 是中文，不能只保留英文文件名；霞鹜文楷的第一个家族名是繁体别名，已校验预设使用清单中的稳定家族名，而不是盲目取第一个名称记录。这个覆盖仅用于预设，不改变旧上传字体的命名行为。
- 渲染器优先匹配完整家族和地区版本，再选择字重。字体安装、上传、删除后会使当前服务进程中的字体索引失效，在下次排版时刷新，避免已经加载的渲染器继续用旧的简繁回退字体。
- `frontend/src/assets/font-previews/` 是从同一固定版本生成的静态 SVG 字形图，不包含字体软件。它们只展示固定样句；下载后才使用完整字体进行自定义文字预览。浏览预设不会下载 10–25 MiB 的整份 CJK 字体。

后续更新预设时，需要重新核对授权、家族名、语言样句、文件长度和摘要，并更新字形图。字体包可能需要访问 GitHub Raw；不可访问时应显示错误并保留原有字体库，不能静默换用未经验证的镜像。
